# Deep Learning Lab

This repository contains implementations of various deep learning experiments using both PyTorch and TensorFlow.

## Experiments

### 1. Machine Learning Fundamentals
- `1_a_decision_tree.py` - Decision Tree classifier on Iris dataset
- `1_b_svm.py` - SVM with decision boundary visualization
- `1_c_gradient_descent.py` - Gradient descent implementation + visualization
- `2_linear_regression.py` - Linear regression on synthetic data + visualization

### 2. Neural Networks
- `3_image.py` / `3_tensor.py` - Image classification
- `4_Neural_network.py` / `4_tensor.py` - Feedforward Neural Network on CIFAR-10
- `5_initialization_regularization.py` / `5_tensor.py` - Weight initialization and regularization
- `6_Digit.py` / `6_tensor.py` - MNIST digit classification

### 3. Convolutional Neural Networks
- `7_Digit_VGGNet.py` / `7_tensor.py` - VGGNet implementation for digit classification

### 4. Recurrent Neural Networks
- `8_RNN_imdb_kaggle.py` / `8_RNN.py` / `8_tensor.py` - RNN for IMDB sentiment analysis
- `9_RNN_LSTM.py` / `9_Tensorflow.py` - RNN vs LSTM vs GRU comparison

### 5. Advanced Applications
- `10_NIFTY.py` / `10_tensor.py` - Stock price prediction
- `11_Machine_Translation.py` / `11_tensorflow.py` - English-Hindi translation

### Additional Files
- `z_labexam.py` - Lab exam question: Spam Detection using GRU
- `sample3.png` - Sample output/visualization
- `viva.docx` / `viva 2.docx` - Viva questions and answers
